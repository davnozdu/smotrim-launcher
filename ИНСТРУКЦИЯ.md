## Установка и обновление

- APK берётся из GitHub-релизов: **https://github.com/davnozdu/smotrim-launcher/releases/latest** (файл `smotrim-launcher.apk`).
- **Автообновление**: лаунчер сам проверяет новые релизы и показывает вверху главного экрана зелёную плашку «Доступно обновление» — нажмите **OK**, чтобы установить.
- Проверить вручную: **Настройки → Система → Проверить обновление**.
- Сборки подписаны постоянным ключом, поэтому обновления ставятся поверх предыдущей версии.

## Сделать лаунчером по умолчанию

**Способ 1 (простой и безопасный):** переназначьте кнопку Home пульта на запуск Smotrim.CZ Launcher через [Key Mapper](https://github.com/keymapperorg/KeyMapper).

**Способ 2 (отключить штатный лаунчер, через ADB):**
```shell
adb shell pm disable-user --user 0 com.google.android.apps.tv.launcherx
adb shell pm disable-user --user 0 com.google.android.tungsten.setupwraith
```
Вернуть обратно:
```shell
adb shell pm enable com.google.android.apps.tv.launcherx
adb shell pm enable com.google.android.tungsten.setupwraith
```
> ⚠️ Делаете на свой риск. Команды проверены на Chromecast with Google TV; на других устройствах могут отличаться. В режиме отеля лаунчер закрепляется как Home автоматически (см. ниже) — отдельно ничего отключать не нужно.

## Главный экран и кнопки

Внизу главного экрана, под приложениями:

- **Продлить подписку** — открывает инструкцию по оплате: перевод на счёт с готовым QR-кодом Czech QR Platba (сумма 1000 Kč уже вшита) или оплата картой через QR SumUp. Показаны пометки про обработку в рабочее время и SMS-подтверждение.
- **Установить / Обновить Smotrim Плеер** и **Установить / Обновить HLS-PROXY** — одно нажатие проверяет установленную версию против последнего релиза на GitHub и ставит/обновляет (или сообщает, что версия уже последняя).
- **Магазин приложений (AppHub)** — открывает магазин `tv.smotrim.cz` (см. ниже).

Индикатор сети (Wi-Fi/Ethernet) рядом с шестерёнкой показывает состояние соединения.

## Магазин приложений (AppHub)

Кнопка **«Магазин приложений»** открывает сайт **tv.smotrim.cz** во встроенном браузере на весь экран.

- **Навигация пультом**: стрелки двигают синюю рамку выбора, **OK** открывает карточку приложения.
- **Установка**: нажмите **OK** на «Установить» — приложение скачается и откроется установщик. Лаунчер сам берёт последний релиз с GitHub (для KinoTrend/NUM — с хостинга).
- **Кнопка «Назад»**: внутри карточки — возврат на главную сайта; на главной — спросит подтверждение выхода («Выйти из магазина?», фокус на «Да»).

В каталоге: лаунчер, плеер, HLS-Proxy, SmartTube, TorrServe, KinoTrend, NUM.

## Режим отеля (киоск)

Режим отеля превращает приставку в **киоск**: гость видит и запускает только разрешённые приложения (ТВ, YouTube и т.д.). Google Play скрыт, системные настройки недоступны, factory reset / safe boot / ADB / удаление приложений заблокированы. Единственный вход в админ-панель — **8-значный ПИН-код владельца**. **Скрытых кодов и бэкдоров нет.** Забытый ПИН восстанавливается только полным сбросом устройства.

### Шаг 1 — Подготовка Device Owner (один раз)

Настоящая блокировка работает только когда лаунчер назначен **Device Owner**. Device Owner ставится, когда на устройстве **нет других пользователей и нет аккаунтов** — но **factory reset и «пропуск входа» НЕ нужны**: достаточно временно снять аккаунт, поставить Device Owner и вернуть аккаунт обратно.

```shell
# Включите ADB на ТВ (Настройки → Об устройстве → 7 раз по «Сборка»
# → Для разработчиков → Отладка по USB/сети), затем с компьютера:
adb connect <ip-приставки>:5555

# 1) Удалите лишних пользователей (оставить только 0 / Владелец):
adb shell pm list users
adb shell pm remove-user <id>          # для каждого пользователя, кроме 0

# 2) Снимите все аккаунты (Настройки → Аккаунты → Удалить). Открыть экран:
adb shell am start -a android.settings.SYNC_SETTINGS
#    проверьте, что аккаунтов не осталось (вывод должен быть пустым):
adb shell dumpsys account | grep "Account {"

# 3) Назначьте Device Owner:
adb shell dpm set-device-owner cz.smotrim.launcher/.HotelAdminReceiver
#    → Success: Device owner set to package cz.smotrim.launcher/.HotelAdminReceiver

# 4) Верните Google-аккаунт обратно, чтобы работали YouTube и др.:
adb shell am start -a android.settings.ADD_ACCOUNT_SETTINGS
```

Добавить аккаунт **после** установки Device Owner можно на большинстве устройств (лаунчер аккаунты не запрещает). Проверено на Xiaomi Mi TV (Android 14).

> Без Device Owner режим отеля — **косметический**: он прячет баннер и служебные кнопки, фильтрует список приложений и закрывает наши настройки ПИН-кодом, но Google Play и системные настройки **реально не блокируются**, и настойчивый гость сможет выйти. Подходит для доверенных гостей, но это не полноценный запрет.

**Не слетит ли режим, если потом добавить пользователя/аккаунт?** Нет. Device Owner **постоянный** — добавление или удаление аккаунтов и пользователей его не снимает. Он снимается только полным factory reset, удалением лаунчера (а в режиме отеля это заблокировано) или если лаунчер сам откажется от прав. Пока режим отеля включён, добавление новых пользователей запрещено.

### Шаг 2 — Настройка (в лаунчере)

**Настройки → Режим отеля:**
1. **Задайте 8-значный ПИН-код** — вводится **дважды** для подтверждения.
2. **Отметьте приложения**, доступные гостю (ТВ, YouTube и т.д.).
3. *(по желанию)* **Автозапуск приложения** — выбранное приложение запускается само при включении приставки, и гость сразу попадает на него.
4. **Включить режим отеля.**

### Шаг 3 — Ежедневное использование и админ-панель

- В заблокированном режиме на главном видны **только разрешённые приложения** (баннер и все служебные кнопки скрыты), а в настройках доступен **только экран разблокировки**.
- Введите ПИН — откроется **админ-панель**:
  - **Сбросить данные гостя** (на выезд) — стирает данные **и кеш** гостевых приложений, оставляя те, что вы отметили тумблером (например, ТВ остаётся залогиненным). Выбор запоминается.
  - **Сброс данных по приложениям** — отметьте конкретные приложения и очистите только их.
  - **Сменить ПИН-код** — новый вводится дважды.
  - **Выйти из режима отеля** — вернуться к обычному лаунчеру.
  - **Полный сброс устройства** — factory reset, с подтверждением.

### Безопасность и восстановление

- ПИН хранится в виде солёного SHA-256 (не в открытом виде); 5 неверных попыток → блокировка на 1 минуту. **Мастер-кода в сборке нет** — ПИН владельца единственный путь.
- Блокировка работает на уровне ОС (Device Owner lock-task), а не только в интерфейсе — Настройки/Play нельзя запустить, потому что их нет в белом списке.
- Заблокированы ADB-отладка, factory reset, safe boot и удаление, чтобы извне нельзя было стереть данные или удалить лаунчер. Держите загрузчик (bootloader) залоченным — перепрошивку прошивки не закроет ни одно приложение.
- **Забытый ПИН:** единственное восстановление — полный factory reset приставки (так задумано, бэкдора нет).
